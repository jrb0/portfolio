# Codebook Federal Transit Administration - 2023 Annual Energy Consumption and Fare Data

## Summary

I created this codebook using data published by the U.S. Federal Transit Administration on reported energy consumption and collected fares for public transportation services nationwide in 2023. The R code - available [here](https://github.com/jrb0/portfolio/blob/main/Codebook.R) and linked below - uses various tidyverse packages (dplyr, tidyr) to wrangle and clean data. As indicated in the code annotations, I merged two separate data sets based on a unique county identifier, cleaned the data to standardize NA codes and remove superflous information, pivoted a previously untidy variable, and displayed summary statistics for each variable along with basic descriptive information.
