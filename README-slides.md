These slides - created using the R markdown Xaringan extension - are an investigation into the effects of an MLB team's success (measured in wins) on rent prices in the zip code surrounding their home stadiums. I conducted a regression analysis in R (controlling for city-wide rent prices) which revealead a statistically significant positive relationship between wins and rent prices, with each additional win associated with a ~$2.75 increase in monthly rent price.

The analysis was conducted using data from Zillow's publicly-available ZORI index, as well as historical wins data pulled using the "Lahman" R package. The slides include visualizations of the relationship, regression results, and recommendations for future study. They can be found at the link below:

https://jrb0.github.io/sis750-slides/#1
